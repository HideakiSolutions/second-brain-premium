# `_sessions/` — Braindumps e Logs de Sessão

Captura bruta e arquivo histórico de sessões.

## O que vive aqui

| Tipo | Origem | Função |
|---|---|---|
| `YYYY-MM-DD-braindump.md` | `/braindump <texto>` | Captura de ideias livres, conectadas ao vault via WikiLinks |
| `auto-captures-archive-YYYY-MM-DD.md` | `/review-captures` ou `/end-session` | Inbox consolidada — arquivo histórico do que foi promovido ou descartado |

## Convenções

- Braindumps preservam contexto bruto; refinamentos vão para `_learnings/` ou `_decisions/`
- Arquivos são append-only; nunca editar entradas existentes
- Diretório nasce vazio; popula com o uso
