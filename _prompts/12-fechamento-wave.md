# Fechamento De Wave

Use ao encerrar wave, PR ou release candidate.

## Prompt

Feche a entrega com evidencias: git status, commits/PRs, validacoes, gaps aceitos, captures pendentes em `_pipeline/inbox/`, docs atualizadas e registro de sessao. Separe mudancas do escopo de alteracoes pre-existentes e nao reverta trabalho alheio.

## Saida Esperada

- Escopo entregue.
- Validacoes e resultados.
- PR/merge/tag, se houver.
- Captura assistida pendente, se houver.
- Proximos passos.
